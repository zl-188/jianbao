# 把每日简报部署到 GitHub Pages · 手把手教程 目标：建一个免费的 GitHub Pages 站点，把每天的《今日简报》HTML 放上去， 得到一个固定网址（如 https://你的用户名.github.io/jianbao/），手机、电脑都能打开。 全程在浏览器里点鼠标，不用装任何软件，不用写命令。 先说清代价：免费版必须用**公开仓库**，简报等于全网可见，没有密码门； 且 github.io 在国内打开偏慢、时好时坏（适合当备份，不适合当主站）。 --- ## 第一步：建仓库 1. 打开 https://github.com 登录（没有账号先注册，免费）。 2. 右上角「+」→「New repository」。 3. 填写： - Repository name：`jianbao`（英文小写，别用中文） - Visibility：选 **Public** - 勾选 **Add a README file** 4. 点「Create repository」。 ## 第二步：开启 GitHub Pages 5. 在仓库页面点「Settings」→ 左侧菜单点「Pages」。 6. 「Build and deployment」里： - Source 选 **Deploy from a branch** - Branch 选 **main**，文件夹选 **/(root)**，点「Save」。 7. 等 1–2 分钟，刷新这个设置页，顶部会出现： 「Your site is live at https://你的用户名.github.io/jianbao/」 这就是你的简报站地址，先收藏好。 ## 第三步：做首页 index.html（简报目录页） 仓库根目录没有 index.html 时，站点首页只会显示 README，所以自己建一个： 8. 回仓库主页，点「Add file」→「Create new file」。 9. 文件名填 `index.html`，内容粘贴下面这份： ```html 每日简报

每日简报

``` 10. 拉到底点「Commit changes」。 ## 第四步：每天发一期简报（约 2 分钟） 11. 拿到当天的简报 HTML 文件，文件名保持这种格式：`jianbao-2026-11-09.html` （必须英文+数字，中文文件名会让链接出问题。） 12. 仓库主页点「Add file」→「Upload files」，把文件拖进去，点「Commit changes」。 13. 再打开 `index.html`，点右上角铅笔图标编辑，在 `
    ` 里最上面加一行： ```html
  • 今日简报 · 2026-11-09
    • ``` 14. 点「Commit changes」。等约 1 分钟，打开站点地址，新的一期就在目录最上面，点开检查排版。 ## 常见问题 - **打开站点是 404**：多半是 Pages 还没构建完，等 1–2 分钟再刷新；或回第二步确认 Branch 选的是 main /(root)。 - **改了文件页面没变**：浏览器缓存，强制刷新（手机上关掉页面重开）再看。 - **上传失败**：网页端单文件上限 25 MB，简报只有几十 KB 不会超；真超了多半是传错了大文件。 - **国内打开很慢/打不开**：github.io 的通病，换手机流量多试两次；这也是它只适合当备份的原因。 ## 和现有流程的衔接 现在每天的简报 HTML 是早上 6:00 的任务生成后自动上传博客的。 GitHub 这边要同步一份的话，最简单的办法：让 Muse 每天把当天的 HTML 文件发到聊天里， 你下载后按第四步上传即可，全程多花约 2 分钟。
